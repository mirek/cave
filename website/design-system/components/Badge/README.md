Badge: a small mono tag with 2px corners, used as an eyebrow above a heading or as a version or property chip.

## Props

- `variant`: `brand` (`brand-tint` wash with a `brand` dot; the eyebrow) · `default` (ink) · `secondary` · `outline`. The consumer supplies a short phrase.

## Use

- Above a hero or CTA heading use `brand`, once per section.
- Version numbers use `default`; properties (`append-only`, `local-first`) use `secondary`.
- Sentence or lower case, no period, under five words. A badge is not a status light: status uses the `meta` style with a dot.
