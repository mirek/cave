HomeHero: a showcase of the Home page's first screen in the new look — header, hero, live code slab and property strip — composed from the system's parts.

## Composition

- Ground: `background` with a faint dot grid in `border` at a 24px pitch (graph paper), only behind the hero.
- Left: `brand` badge eyebrow, `hero` h1 with one phrase in a `.hl` highlight (`brand-tint`), a `lead` paragraph capped at 56ch, a `default` + `outline` button pair, and the install command in mono with an orange `$`.
- Right: a CaveCode `.code-frame` with line numbers and a query footer.
- Below: the property strip on `muted` in `meta` style, each item led by a small `brand` square.

## Use

- One highlight per heading. Orange stays small on this screen — dots, the mark’s bar, the highlight, the button’s offset and code verbs; no large orange area here.
- Copy is the site's own; keep it.
